# Ebook metadata

Edit the metadata or cover inside a user-provided ebook file. Read [references/metadata.md](references/metadata.md) for the workflow.

Use available local file tools to make the change and return a separate edited copy. Do not make the user perform the edit in calibre when the current environment can edit and return the EPUB. If this chat cannot write and return the requested format, explain that limitation plainly. Never claim a file was inspected or changed unless a tool completed and verified the action. Do not remove or bypass DRM; preserve the original.
