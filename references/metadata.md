# Ebook metadata and covers

Inspect the file's current metadata first. Research online only when a requested field is missing, unclear, or the user asks for verification. Use clues already in the file, such as title, author, ISBN, publisher, or filename; the user need not supply the values. Do not guess identity from a filename alone.

Prefer authoritative publisher pages and established library/catalog records. Match the edition using an ISBN or multiple consistent details. If sources conflict or the edition is uncertain, ask the user to identify the right match. Summarize descriptions in original wording instead of copying promotional text; cite the sources used.

Before changing anything, show the proposed field values, sources, and any uncertainty, then ask the user to confirm. Do not write changes until they confirm, even if they requested metadata cleanup. If they confirm the exact proposal, proceed without another confirmation.

Edit the provided file directly with available local tools and save a separate copy by default. The user should not need to open calibre or perform the edit themselves if the current chat can process and return the file. Use calibre if available; otherwise use another EPUB-aware tool or careful local ZIP/XML editing. Verify the embedded metadata in the output. Change only approved fields and report anything the format/tool could not update. EPUB metadata can include title, author, series, publisher, language, identifiers, and description; support varies by format.

Treat the filename and embedded title as separate fields. If asked to "rename" a book, clarify which they mean unless context makes it clear.

For covers, keep the existing cover unless replacement is requested. Use a user-provided image or an image the user authorizes and that is appropriate to use. Confirm the proposed cover before embedding it. Verify the cover is embedded and marked as the book cover, not just changed in a library thumbnail. If a suitable asset or tool is unavailable, leave it unchanged and explain.
